What changed
  • The paperclip is an icon, not an emoji A 📎 renders in the platform’s own colour — the one thing colour is reserved for here is status. It’s ti-paperclip now, inheriting text-ink-faint.
  • Two icons, not two labels “Attach to Inbox” is gone — there is just attach. Attach and paste transcript are quiet 32px ghost icon buttons, the same one used for + in the tab bar, so neither matches Send’s weight.
  • One control row, tightened The row sat 14px below the field with 10px gaps between mismatched pills. Controls now share a 4px-gap cluster on the left, keys and Send on the right, and everything aligns to the field’s 4px text inset.
  • Attached files are visible There was nowhere for an attachment to appear. Files sit above the field as chips — type icon, truncated name, mono size, and a remove × — so you can see and undo what you’ve staged before sending.
  • Paste attaches Paste a file or a screenshot and it becomes a chip; paste text and it goes in the field. The clipboard button is for the other case — pulling in a long transcript as an attachment rather than dumping it into the draft.
  • Drag has a state Dropping a file on a composer is the common way to attach. The panel borrows border-line-accent and shows a dashed “Drop to attach” target, replacing the control row so there’s one instruction on screen.
  • Send reads its own state Disabled was a bordered button in bg-surface-control-hover — brighter than its enabled self on some surfaces. Disabled is now flat bg-surface-control with text-ink-disabled; enabled steps up on hover.
  • No keyboard hint The mono ⏎ send · ⇧⏎ newline legend is gone. It was permanent instructions for a convention people learn once, sitting in the composer’s only quiet space.
