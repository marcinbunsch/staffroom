What changed
  • Chat creation lives in one place The dialog’s footer “New chat” button is gone — the tab bar’s + already owns that action, and a modal history is for returning to work, not starting it.
  • No count pill The header chip counted rows the user can already see. The dialog now carries only its label; the count that is useful sits on the History button, where it tells you something before you open anything.
  • Main is not history The persistent thread never appears in the list — it can’t be closed or deleted, so it has no business in a list whose verbs are “reopen” and “delete”.
  • Type collision fixed The old title carried text-secondary font-medium text-ink-primary and font-mono text-label uppercase text-ink-label — two type roles fighting. Now it is one: the panel-label role.
  • No shadow, no stock width shadow-xl and max-w-xl were off-system. Depth is a surface step plus a 1px border over a dimmed backdrop; width is an explicit 520px.
  • Status became a channel “open” / “closed” were identical grey mono strings. Open now carries the working dot and a blue label; closed is idle grey — readable in one pass, in the list and on the tabs.
  • Rows read as rows Two lines instead of four competing columns: title (plus branch chip) over a mono meta line. Nothing goes ragged when a chat has no branch.
  • Time stops jumping The 92px reserved column is gone — the timestamp yields to the delete button on hover, which is pointer-events-none until it’s actually revealed.
  • Tabs earn their pill The active tab is the only filled one (bg-surface-selected + border-line-strong); the rest are quiet text until hovered. Each carries a status dot, and closable tabs reveal a × in reserved space so labels never reflow.
