Tailwind design system

Every token in the Staff system, the utility that emits it, and the components built from them. If you are generating UI for this product: the palette below is closed — no stock Tailwind colors, no new hexes, no shadows. Copy the class strings verbatim.

Install

One import. theme.css pulls in Tailwind itself, so do not import Tailwind separately. 

/* app.css — the only stylesheet you need. */
@import "./tailwind/theme.css";

/* theme.css pulls in Tailwind, IBM Plex Sans + Mono, and the Tabler icon
   webfont, so there is nothing to add to your document head. Swap its two
   remote imports for self-hosted @font-face rules in production. */

Theming

Two layers. The variable layer holds every hex; @theme inline maps those variables into Tailwind namespaces. The inline keyword is load-bearing — without it the dark hex is baked into each utility and light never applies. There is no dark: variant in this system. 

document.documentElement.dataset.theme = "light"; // or "dark"

One breakpoint, and it governs chrome only: the rail becomes a top bar plus bottom tab bar. Content is fluid — flex-wrap with flex-basis, clamp() padding, and auto-fit grids. Tailwind’s sm: md: lg: xl: are unused here.

Composition order, on every screen

Needs you → Working now → Recent outcomes. A screen never opens with a metric, a chart, or a greeting card. If nothing needs the operator, the first section is simply absent — no empty state, no “all clear” banner.

Rules that survive the port

These are the ones most easily lost in a utility rewrite.

Color is a status channel

Blue is working, amber needs you, red failed, gray idle, teal private. Never color for hierarchy or emphasis.

No shadows

Depth is a surface step plus a 1px border. There is no elevation scale, so shadow-* never appears.

Exceptions first

Blocked and failed above running, running above done. The operator should never scroll to find a problem.

Motion means live

Three animate-* utilities, for work happening right now. No entrance animations, ever.

Hover changes color

Never geometry. No hover:scale-*, no hover:-translate-y-*, no transform transitions.

One breakpoint, chrome only

mobile: / desktop: at 900px. Content is fluid via flex-wrap, clamp() and auto-fit grids.

Mono for machine facts

Ids, counts, durations, exit codes, tool scopes, paths. Language is always sans.

Privacy reassures

Describe the mechanism — “never leaves this machine”, “retained 90 days”. Teal, not red. No shields.

Counts carry context

“3 open · 1 failure”, not “3”. A bare number is a metric, not information.

Name the action

“Retry 8 sources”, “Private prep only”. Buttons are verbs with objects.

Never

If a generated screen contains any of these, it is off-system.

bg-neutral-900, text-slate-400, bg-blue-500
Any stock Tailwind palette color. Use bg-surface-*, text-ink-*, *-status-*.
dark:*
Theming is data-theme on html plus the variable layer. A dark: variant doubles every decision and drifts.
shadow-sm, shadow-lg, drop-shadow-*
No shadows in this system, at any size.
sm: md: lg: xl: 2xl:
Unused. The only breakpoint variants are mobile: and desktop:.
max-w-prose
Tailwind’s static 65ch utility — a theme token cannot override it. The 720px measure is max-w-copy.
hover:scale-105, hover:-translate-y-0.5
Hover changes color only.
animate-pulse, animate-spin, animate-bounce
Tailwind’s stock animations. Use animate-pulse-dot / pulse-ring / bar-slide.
rounded-full on cards, rounded-2xl
Radius comes from the six-step scale. Full round is for dots and badges only.
Emoji, gradient backgrounds, icon-as-status
Not in this product’s vocabulary. Status is a dot; agents are monograms.
